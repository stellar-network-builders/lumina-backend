# Software Bill of Materials (SBOM)

This directory holds generated SBOMs for the project's dependency trees. SBOMs
are produced in [CycloneDX](https://cyclonedx.org/) JSON format and are used for
supply-chain transparency and compliance audits (SOC 2, ISO 27001).

## Files

| File | Scope | Generated by |
| --- | --- | --- |
| `lumina-backend.cdx.json` | npm production dependencies (`backend/`) | `npm sbom` |
| `lumina-contracts.cdx.json` | Cargo dependencies (`contracts/`) | `cargo cyclonedx` (CI) |

> Generated SBOM JSON files are git-ignored — they are build artifacts produced
> in CI on every push to `main` and published to the workflow run. This README
> and `.gitkeep` are the only tracked files here so the output path always
> exists. See [`docs/dependency-management.md`](../../docs/dependency-management.md).

## Regenerating locally

```bash
# npm SBOM (writes to this directory)
cd backend && npm run sbom

# Cargo SBOM (optional — requires cargo-cyclonedx)
cargo install cargo-cyclonedx
cd contracts && cargo cyclonedx --format json
```
